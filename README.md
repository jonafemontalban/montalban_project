# Delicacy Project

## Summary
Many local delicacies are sold without clear ingredient or allergen information, which puts customers with food allergies at risk and makes it hard for them to choose safely. Delicacy Project is a web system that lists local delicacies together with their allergen information (such as nuts, milk, eggs, gluten, and seafood) so customers can browse and choose with confidence. First features: Home page, Login, and a delicacy catalog with allergen labels.

## Current stack
Flutter Web / Dart; planned REST API and PostgreSQL.

## Run locally
git clone <REPO-URL>
cd delicacy/delicacy_project
flutter pub get
flutter run -d chrome
